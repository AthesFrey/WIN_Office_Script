# drawms

`drawms.xlsm` is a standalone milestone page derived from the 5.6fix3 chart style. It contains one `Milestones` worksheet and three buttons: `Generate Chart`, `Widen Spacing`, and `Narrow Spacing`.

The two input columns are literal text. The workbook does not use WBS links, formulas, date parsing, date sorting, duplicate-date merging, custom undo/redo, or Excel Ribbon overrides. Excel's normal editing history remains available.

Open the workbook in desktop Microsoft Excel with macros enabled. The Linux checks validate the OOXML package and VBA source; they do not replace a desktop Excel run.
