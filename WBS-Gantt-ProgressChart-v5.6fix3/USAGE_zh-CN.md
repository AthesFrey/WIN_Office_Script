# WBS Gantt v5.6fix3 使用说明

使用 Windows 桌面版 Microsoft Excel 2021/2024 打开 `WBS-Gantt-ProgressChart-v5.6fix3.xlsm` 并启用宏。第一张表仍叫 WBS，第二张表仍叫 Milestones。请使用工具包根目录的新工作簿，`source_project/WBS.xlsm` 是构建模板。

Milestones 的按钮与 Sheet1（WBS）使用同一种固定定位方式：不随单元格移动或调整大小。初始布局仍为第 5 行的 Generate、Copy、Widen、Narrow 和第 11～12 行的 Undo、Redo、Delete Level 1–5，顶部间距 3 磅、高度 25 磅。拖动单元格或调整行高列宽时，按钮保持原有工作表坐标；打开、切页和刷新也不再重新定位按钮或强制调整工具栏行高。

## 本次变化

- 修复 fix2 中按钮先随单元格移动、点击后又复位的问题，统一采用 Sheet1 的固定坐标。
- 删除随单元格移动的锚点换算、运行时位置复位过程、重复坐标表及相关调用，详见 `FIX3_NOTES.md`。
- 保留错误 28 防重复进入、Refresh All 失败回滚、日期与来源校验、空 WBS 导入及手动计算判重修复。
- 保留 Milestones 表头上方七个按钮：`Undo (n)`、`Redo (n)` 和 `Delete Level 1–5`。删除只处理恰好对应层级的关联条目，保留其他层级、手工条目和 WBS 原始任务。
- Milestones 与 WBS 各自保留最近三步操作，互不占用步数。蓝色表示可用，灰色点击无动作；数字表示对应方向可用步数。
- Ctrl+Z / Ctrl+Y 跟随当前工作表。此工作簿仍禁用 Excel 原生撤销、恢复和重复按钮；切换到其他工作簿后恢复其原生控制。
- 删除、撤销、恢复后，点击已有 Generate 按钮更新图形。保留 5.6fix2 的 WBS 数据、排期、样式和原有控件。

## 三步撤销与恢复

每张表的三步各自属于同一段历史：完成三次编辑后可依次撤销三次，再依次恢复三次。第四次编辑会移除本表最早的一条。撤销后再做新编辑，本表旧的 Redo 分支会清除。

支持 WBS 第 6 行起 A:Y 正文编辑、一次多格粘贴、清空内容、D2 层级下拉和 Promote / Demote 升降级按钮。快照保存操作前后两种状态，恢复编号、原始数值、公式、普通文本、数字格式、常用正文样式、边框、行高、O 列前置验证及排期联动结果。保留日期显示、前导零、等号开头普通文本和完整计算精度。恢复时直接回放并计算公式及 Milestones 链接，不重新执行排程。

切换选区、D2 随选区显示层级、切换工作表或工作簿不会清除有效记录；无变化或被拒绝的层级操作不占用步数。Ctrl+Z / Ctrl+Y 跟随当前 WBS 或 Milestones 工作表，离开本工作簿或关闭时解除接管。

`Update Gantt`、新增任务和支持范围外编辑沿用 WBS 的历史边界；`Refresh All` 清空两张表的历史，结构性增删行/列会使相关历史失效。历史只在内存中，不随文件保存。纯格式命令不单独记为一步；检测到未记录的正文变化时，旧历史会失效，避免覆盖后续修改。由于 Excel 没有格式修改前事件，在同一选区先改格式再改内容时，该格式可能随这次内容编辑一起撤销。合并/拆分、条件格式编辑、批注、图形和页面设置不属于此历史范围。

在 WBS 向未使用的尾部行做大范围粘贴时，请先选中完整目标区域，便于捕获原内容和格式。WBS 默认至少捕获 1,000 行，并包含任务末尾的前置下拉扩展区；超过已捕获范围时会保留粘贴结果、清除历史并提示。

恢复失败后先解决提示原因（例如解除 WBS 保护），再重试同一方向。程序会恢复 Excel 的事件、计算和屏幕更新设置，尽力回滚失败写入，成功核对后才移动历史。失败后再编辑会开始新的历史。

## Milestones 按级删除与三步历史

点击 `Delete Level 1` 至 `Delete Level 5`，清空 B14:J213 内关联到对应 WBS 当前层级的条目，包括隐藏行和 `Show = No` 的条目。例如删除 2 级只清空 2 级条目，保留 3～5 级条目。整批删除计一步；没有匹配条目时不占步数，也不清除 Redo。

没有有效 WBS 来源的手工条目、示例和来源失效条目保留。判断层级时读取来源任务的当前层级；插入 WBS 行后使用更新后的来源行号。删除只清空匹配行的 B:J 内容，保留行位置、格式和下拉验证，不改动 WBS 原始任务。

Milestones 独立记录 B14:J213 及 C6:C7 的编辑、多格粘贴、清空、整批导入、按级删除和位置/间距设置。快照保留原始数值、公式、普通文本、数字格式、常用样式、边框、行高和验证规则。一次按钮操作中的内部写入合并为一步；纯重画图形不计步，生成时规范化日期或输入格式最多计一步。导入、删除或生成失败会尝试回滚输入变化，回滚失败会明确提示。Refresh All 中图表生成失败同样回滚本次日期和数字格式规范化，再继续其他刷新与字体统一。

删除、撤销或恢复后继续手动点击 Generate 更新图形；旧图保留到下次生成，图形本身不属于历史。间距按钮沿用原来的自动生成行为，撤销间距时只恢复设置。`Refresh All` 清空两页历史；跨出上述捕获范围的粘贴清空本页历史。WBS 重新计算引起的链接值变化不会占步数；插入或删除来源行导致链接公式改变时，旧快照会失效，避免恢复过期引用。

## 保留的操作能力

- 同一天完成的 Milestones 任务共用一个三角、日期框和任务文本框，名称按原输入行顺序用 `; ` 连接；仍按输入任务数量限制最多 60 条。
- `Refresh All` 调用 `Update Gantt` 的同一套排程、甘特图和异常检查，再生成 Milestones；里程碑失败时清理旧图并重试，仍失败则在 Milestones B10 记录原因、跳过生成并继续正文格式和历史清理。单独生成及间距按钮采用同样的重试方式；排程错误仍会停止刷新。
- 刷新后 F 列 Days 与 `结束日期 - 开始日期 + 1` 不符时标浅红色。同一父任务的直接子任务（顶层任务共用一个父级组）中，当前行与上一条同组任务在表内相邻，且开始日期不等于上一条结束日期加一天时，当前行 G 列标浅黄色。跨行、首条或相关日期不可读时不标黄。警告通过工具专用条件格式显示，重新刷新会移除过期标记并显露原有底色。
- `Refresh All` 后，WBS 的 B6:Y 任务区及甘特任务行、Milestones 的 B3:J10 和 B14:J213 均为微软雅黑 11 号；标题、表头、按钮、进度图形文字保持原样。WBS/Gantt 字体设置也在 `Update Gantt` 内执行。

Days 沿用包含首尾两天的算法，检查的是自动排程和计算完成后的结果；正常的数值 Days/开始日期仍会按原规则自动生成结束日期。

## 批量调整层级

1. 在 WBS 选中多个任务的单元格或整行；可以拖选，也可以按 Ctrl 不连续多选。
2. 点击 D2 的 Level 下拉框，选目标级别；也可点击 `Promote (-1)` 升一级或 `Demote (+1)` 降一级。
3. 选中的父任务会带着子任务一起移动，子任务相对层级保持不变。父子同时选中只处理一次；下拉框的目标级别应用到各选中子树的根任务。

例如两个同为 3 级的任务，选择 Level 2 后一起变成 2 级。点击 Promote 后级别数字减 1，点击 Demote 后数字加 1。

不同级别混选时，D2 暂时显示空白。选择 D2 不会清除刚才记住的任务选择。批量操作不能超出 1～5 级、不能跳过父级、不能把第一条任务改成子任务；非法操作会先提示，不会只改一部分。如果层级变化形成排期循环依赖，会恢复捕获的正文、层级、前置引用和联动结果。

## 其他操作

- `Add Task`：在所选任务的整个子树之后插入同级任务。
- `Add Subtask`：增加下一层任务。
- 叶子任务填写 G 列开始日期、F 列天数、N 列进度。修改 H 列结束日期会反算天数。工期包含周末，首尾都计入。
- 日期支持 `2026/9/16`、`20260916`；`0916` 或 `916` 使用同一列紧邻上一行的年份。上一行没有有效日期时需输入完整日期。
- 父任务自动汇总所有下属叶子的最早开始、最晚结束、跨度和按工期加权的进度。O 列前置任务会让当前任务从前置结束的下一天开始。
- `Update Gantt` 重画甘特图，并检查 Days 和同组相邻任务的日期顺序。Days 不匹配时 F 列标浅红色；同一父任务下相邻子任务的开始日期没有接在上一任务结束日后时，G 列标浅黄色。`Refresh All` 复用同一套甘特图刷新，再更新里程碑图，并将两张表正文刷新为微软雅黑 11 号。
- Milestones：清除 B:J 示例后，可从 WBS 多选导入；或手填名称、日期和 `Show = Yes`，再生成。支持 60 条输入任务、每个名称最多 120 字符；相同完成日期的任务合并为一个节点，名称用 `; ` 分隔；支持等间距、日期比例及间距调节。
- `Copy Chart` 可复制到 Word / PowerPoint。不要另存为 `.xlsx`，否则宏会丢失。

## 验证范围

本次 Linux 环境没有桌面版 Excel，未执行按钮、快捷键或 COM 运行测试。主脚本载入 `tests/excel_milestones.ps1` 与 `tests/excel_regressions.ps1`；三份脚本均通过语法解析。布局场景检查首次打开、80%/100%/125% 缩放、拖移单元格、增减行高列宽、切页、按钮生成、全刷新和保存重开。行列调整及剪切移动后立即核对位置，同时覆盖事件关闭和开启状态，避免点击后复位掩盖错误。保留五级删除、两页三步历史、格式粘贴、失败回滚、异常日期和来源、空表导入及手动计算判重等场景。脚本只读打开交付文件，关闭不覆盖原文件；保存重开使用临时副本。脚本不更改宏安全设置，键盘场景需保持 Excel 在前台。

```powershell
pwsh -File tests/excel_smoke.ps1 -WorkbookPath ../WBS-Gantt-ProgressChart-v5.6fix3.xlsm
```

尚需在 Windows Office 2021/2024 运行以上脚本，并检查实际鼠标按钮、另存为及取消关闭提示、恢复中途失败、非法日期提示、Excel 编译/修复提示和 PowerPoint 复制效果。已执行的文件回归、语法及 OOXML 检查详见检查结果文档。
